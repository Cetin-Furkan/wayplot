# ISO C23 Conventions

Every translation unit is compiled `-std=c23`. `__STDC_VERSION__` must be `>= 202311L`. Headers abort at preprocess time if the compiler is older.

## Banned headers

| Banned | Why | Use instead |
|---|---|---|
| `<stdbool.h>` | `bool` / `true` / `false` are keywords | language keywords |
| `<stdalign.h>` | `alignas` / `alignof` are keywords | language keywords |

Every public header and every `.c` file carries:

```c
#ifdef _STDBOOL_H
#error "<stdbool.h> is strictly banned. ..."
#endif
#ifdef _STDALIGN_H
#error "<stdalign.h> is strictly banned. ..."
#endif
```

`make lint` and CI grep for `#include <stdbool.h>` and `#include <stdalign.h>`.

## Required idioms

- `nullptr` instead of `NULL` or `(void*)0`
- `constexpr` for scalar constants and array bounds (typed, not `#define`)
- empty initializer `= {}` instead of `memset(..., 0, ...)`
- C23 digit separators in literals: `4'096`, `65'536`, `2'097'152`
- `auto` for locals when the type is obvious from the initializer
- `[[nodiscard]]` on functions whose return must be checked
- `[[maybe_unused]]` on parameters kept only for ABI / kernel struct symmetry
- `static_assert` for size / layout invariants

## Digit-separator trap

`64'536` is **64536**, not 64 KiB. 64 KiB is `65'536` (`64 * 1024`). The PBUF tier-1 size was wrong until this was caught. When you mean a power-of-two binary size, write `65'536` or `64u * 1024u`, never `64'536`.

## VLAs

`-Werror=vla`. Fixed-size arrays only. `uint8_t buf[4'096]` is fine; `uint8_t buf[n]` is not.

## `_GNU_SOURCE`

Defined globally by the Makefile (`-D_GNU_SOURCE`). `include/engine.h` errors if it is missing. Do not `#define _GNU_SOURCE` inside individual files (redefinition warnings). Need it for `pthread_setaffinity_np`, `sched_getcpu`, `O_DIRECT`, `CPU_SET`.

## Attributes helper

`include/khoros/core/attributes.h` defines `KHR_NODISCARD`, `KHR_MAYBE_UNUSED`, `KHR_DEPRECATED` as aliases of the standard attributes. Prefer writing `[[nodiscard]]` directly, matching the rest of the tree.
